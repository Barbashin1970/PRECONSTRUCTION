# AI Tools for Presale Research

Tools fall into two groups: **research tools** (LLMs/AI agents for stages 1–5) and
**specialized tools** (for technical tasks where LLMs are not suitable — see
[07](07-case-llm-limits.md)).

## Research LLMs / AI agents (free)

| Tool | Strengths | Access | Limitations |
|---|---|---|---|
| **DeepSeek** | Technical accuracy, reasoning (R1), code, mathematics | `deepseek.com`, email, free | No voice/images, basic UI |
| **GigaChat** | Russian language, construction terminology, context of Russian building codes, images (Kandinsky), presentations up to 12 slides | `giga.chat`, Sber ID | — |
| **Perplexity** | Search with sources, up-to-date data | `perplexity.ai` | Free: 5 queries / 4 h; Pro $20/mo → GPT-4, Claude |

Recommended split: **DeepSeek** — technical expertise and critique of AI applicability;
**Perplexity** — identification and business analysis (when sources are needed); **GigaChat** — packaging
(Russian texts, presentations).

## Perplexity Spaces — teamwork

- Create a **Space** for the project; upload PDF instructions (the role methodology).
- Set **Custom Instructions** for role-based agents (business analyst, marketer,
  AI systems analyst, packager) — see [03](03-ai-agent-roles.md).
- A separate **thread for each stage** of the presale; shared access for the team.

## Packaging tools

Gamma.app, Canva, Google Slides + ChatGPT, GigaChat — presentation generation. See
[05](05-pitch-packaging.md).

## Specialized platforms (NOT LLMs)

For technical tasks (for example, recognizing dimensions on drawings) LLMs head-on do not
work. Specialized solutions are used instead:

- **KREO**, **Togal.AI**, **Bluebeam Revu** — takeoff / calculation of quantities and estimates from drawings.
- Computer vision, BIM plugins — for spatial analysis.

> **Selection rule.** An LLM/AI agent is for **finding and comparing** such platforms (market
> research, ranking by accuracy/price/ROI), not for performing the technical work itself.
> Adopt specialized software only after testing it on real drawings. In detail —
> [07 — limits of LLMs](07-case-llm-limits.md).
