# Бэклог PRECONSTRUCTION

Память об отложенном: что заметили, почему не делаем сейчас и по какому признаку
вернёмся. План работ — в [разборе пакета](PAKET-RAZBOR.md), сценарии — в
[USE-CASES.md](USE-CASES.md).

## 1. Навыки в мобильных приложениях Claude

**Повод.** 2026-11-02, разбор пакета: справка «Using Skills in Claude» описывает загрузку
через «Customize → Skills» и работу в чате и Cowork; о приложениях для iOS и Android
в ней ни слова.

**Что именно.** Проверить на телефоне: виден ли загруженный с компьютера навык в чате
мобильного приложения и срабатывает ли он. По итогу — строка в STUDENT-SETUP.

**Почему не сейчас.** Проверить может только автор на своём телефоне и своей учётной записи.

**Что будет, если не делать.** Слушатель с одним телефоном не знает, получится ли;
обходной путь — мобильный браузер на claude.ai.

**Признак, что пора.** Первый вопрос слушателя «а с телефона можно?».

**Оценка.** Десять минут.

## 2. Загрузка навыка через Skills API

**Повод.** 2026-11-02: навыки, загруженные в claude.ai, не появляются в API, и наоборот.

**Что именно.** Короткий раздел и сценарий загрузки архива через `/v1/skills` для тех,
кто строит своё приложение на API.

**Почему не сейчас.** Аудитория курса работает в чатах и Claude Code; в API у навыка
нет сети, а потокам нужен веб-поиск — без него все цифры уйдут в «гипотезу».

**Что будет, если не делать.** Разработчик соберёт загрузку сам по документации Anthropic.

**Признак, что пора.** Запрос на встраивание навыка в чужой продукт или в бота.

**Оценка.** Одна сессия.

## 3. Прогон проверок поведения

**Повод.** 2026-11-02: в `evals/` три случая для `claude plugin eval`, ни разу не запущены.

**Что именно.** `claude plugin eval . --max-cost-usd 5` из корня репозитория; при отказе
`skill-fired` — править описание навыка, а не проверку.

**Почему не сейчас.** Прогон тратит лимиты учётной записи автора; запускать — решение автора.

**Что будет, если не делать.** Неизвестно, срабатывает ли навык на естественную фразу
без явного `/preconstruction-ru`.

**Признак, что пора.** Перед очередным потоком курса или после правки описания навыка.

**Оценка.** Полчаса плюс стоимость прогона.

## 4. Лицензия — закрыто 2026-11-02

**Закрыто 2026-11-02.** Автор: «как в PROMPT-Professor». Тексты и навыки — CC BY 4.0
(`LICENSE-CONTENT.md`, поле `license` в обоих `SKILL.md`), код — MIT (`LICENSE`);
в `plugin.json` — `"MIT AND CC-BY-4.0"`. Исходные материалы `knowledge-base*/sources/`
оставлены на условиях их авторов — если они авторские, исключение можно снять.

**Повод.** 2026-11-02: в репозитории нет файла лицензии, в `plugin.json` нет поля `license`.

**Что именно.** Выбрать условия. Образец — PROMPT-Professor: тексты и навыки CC BY 4.0,
код MIT. Отдельно решить про `knowledge-base/sources/` — это материалы НГУ/НГАУДИ.

**Почему не сейчас.** Выбор лицензии — решение автора, а не агента.

**Что будет, если не делать.** Публичный репозиторий без лицензии формально запрещает
копирование и переделку, а навыки как раз раздаются для копирования.

**Признак, что пора.** Сейчас — до объявления репозитория слушателям.

**Оценка.** Пять минут после решения.

## 5. PDF в составе плагина

**Повод.** 2026-11-02, решение Р-1: плагин — весь репозиторий, и `AI-BASE.pdf`
с `Preconstruction.pdf` (около 9 МБ) копируются в кэш плагина у каждого пользователя.

**Что именно.** Перенести PDF в выпуски GitHub (Releases) или в отдельную папку вне плагина.

**Почему не сейчас.** На эти файлы могут ссылаться слайды и QR-коды; вес терпим.

**Что будет, если не делать.** Установка плагина тянет лишние мегабайты.

**Признак, что пора.** Жалоба на долгую установку или третий PDF в корне.

**Оценка.** Полчаса.

## 6. Каталог плагинов Anthropic

**Повод.** 2026-11-02: плагин можно подать в каталог Anthropic, тогда его ставят без
добавления маркетплейса.

**Что именно.** Подача по инструкции «Submit to Anthropic's directory»; для неё нужны
поля `icon`, `documentationUrl`, `supportUrl` в `plugin.json`.

**Почему не сейчас.** Сначала обкатка на курсе; нужна лицензия (п. 4).

**Что будет, если не делать.** Ставят через `/plugin marketplace add` — на одну команду больше.

**Признак, что пора.** Навык прошёл поток курса без правок по существу.

**Оценка.** Одна сессия.

## 7. install.ps1 не прогонялся на Windows

**Повод.** 2026-11-02: установщик для Windows написан и прочитан, но не исполнен —
под рукой нет Windows.

**Что именно.** Прогнать три режима (`install.ps1`, `-Copy`, `-Uninstall`) в Windows
PowerShell 5.1 и PowerShell 7, в том числе с кириллицей в имени пользователя.

**Почему не сейчас.** Нужна машина с Windows.

**Что будет, если не делать.** Ошибку установщика найдёт слушатель на занятии.
Обходной путь — плагин (СЦ-02) или ручное копирование.

**Признак, что пора.** Первый слушатель с Windows или доступ к Windows у автора.

**Оценка.** Двадцать минут.

## 8. Один архив вместо двух

**Повод.** 2026-11-02, решение Р-3: claude.ai ждёт папку навыка в корне архива,
Perplexity принимал `SKILL.md` в корне; принимает ли Perplexity первый формат — неизвестно.

**Что именно.** Загрузить `zip/claude/preconstruction-ru.zip` в Perplexity. Принят —
оставить один вид архива и упростить инструкции.

**Почему не сейчас.** Проверка — загрузкой в учётную запись автора.

**Что будет, если не делать.** Два каталога архивов; слушатель может взять не тот.

**Признак, что пора.** Следующая загрузка автором в Perplexity.

**Оценка.** Пять минут.

## 9. Предел описания в claude.ai

**Повод.** 2026-11-02: справка «Creating custom Skills» говорит о 200 знаках для описания,
документация платформы и спецификация — о 1024. Наши описания — около 500–650 знаков.

**Что именно.** Если claude.ai отклонит архив из-за длины описания — сократить описание
до 200 знаков, а триггерные слова перенести в первый абзац `SKILL.md`.

**Почему не сейчас.** Справка, по всей видимости, устарела: валидатор самой Anthropic
(`quick_validate.py` в навыке skill-creator, 2026-11-02) проверяет предел 1024 знака и наши
архивы принимает; окончательно подтверждает только загрузка.

**Что будет, если не делать.** Ничего, если предел — 1024.

**Признак, что пора.** Отказ загрузки с упоминанием длины описания.

**Оценка.** Полчаса.
