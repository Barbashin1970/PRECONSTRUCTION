# Сценарии использования — навыки PRECONSTRUCTION

Сквозная нумерация СЦ-01, СЦ-02…; номера не переиспользуются. Основание —
[разбор пакета](PAKET-RAZBOR.md). В поле «Проверки» — чем сценарий сторожится сейчас;
«не автоматизирована» значит, что проверяет человек.

### СЦ-01. Проработать идею

**Кто.** Слушатель курса «ИИ в строительстве», архитектор-градостроитель, инженер, продакт.
**Предусловие.** Навык поставлен любым из путей СЦ-02…СЦ-06.

**Шаги.**
1. Пишет: «проработай идею: …» (или вызывает `/preconstruction-ru`).
2. Отвечает на 2–3 волны вопросов, выбирает глубину «быстрая» или «полная», говорит «поехали».
3. Получает отчёт: в Claude Code — файл `research/<слаг>-<дата>.md`, в claude.ai — файл
   для скачивания, в других чатах — текст ответа; в чате — краткое резюме, питч и вердикт по ИИ.

**Ожидаемый результат.** Пройдены все четыре фазы в любой среде: скоупинг, потоки A–D,
аудит, сведение. У каждого утверждения отчёта — пометка, чем оно подтверждено. Есть
раздел «Применимость ИИ» с вердиктом по компонентам и раздел блокирующих вопросов.

**Что считается отказом.**
* навык сразу пишет отчёт, не задав ни одного вопроса;
* в чате без `Agent` пропущен аудит или потоки слиты в один текст;
* дата в имени отчёта выдумана;
* «ИИ внутри: ДА» без обоснования, почему не хватит классики.

**Проверки.** `evals/ru-idea-scoping-first`, `evals/en-idea-scoping-first` — навык
срабатывает на естественную фразу и начинает со скоупинга (запуск — `claude plugin eval .`,
платный). Полный прогон четырёх фаз не автоматизирован.

### СЦ-02. Поставить в Claude Code плагином — любая ОС

**Кто.** Слушатель с платным Claude (Pro, Max, Team, Enterprise) на macOS, Windows или Linux;
в терминале, VS Code, JetBrains или во вкладке Code приложения Claude.

**Шаги.** `/plugin marketplace add Barbashin1970/PRECONSTRUCTION` →
`/plugin install preconstruction@preconstruction-skills` → выбрать «для себя».

**Ожидаемый результат.** В меню `/` появились `/preconstruction:preconstruction-ru`
и `/preconstruction:preconstruction-en`; без клонирования, без симлинков, одинаково на всех ОС.

**Что считается отказом.** Маркетплейс не добавляется; плагин ставится, но навыков в нём нет.

**Проверки.** `tools/check.py` — манифесты читаются, имена плагина в маркетплейсе
и в манифесте совпадают, версии сходятся; `claude plugin validate .` — у автора.

### СЦ-03. Поставить в Claude Code установщиком

**Кто.** Тот, кто скачал репозиторий и хочет короткие имена `/preconstruction-ru`,
или работает с Codex и другими агентами.

**Шаги.** macOS и Linux: `./install.sh`. Windows: `powershell -ExecutionPolicy Bypass -File .\install.ps1`.
Ключ `--copy` / `-Copy` — копии вместо ссылок, `--uninstall` / `-Uninstall` — убрать ссылки.

**Ожидаемый результат.** Навыки лежат в `~/.claude/skills/` и `~/.agents/skills/`;
повторный запуск ничего не ломает; чужой навык с тем же именем не затёрт.

**Что считается отказом.** Установщик затёр существующую папку; на Windows без прав
администратора упал; после переноса репозитория ссылки молча не работают, а установщик
об этом не предупреждал.

**Проверки.** `install.sh` прогнан на временном домашнем каталоге (см. разбор,
раздел «Закрыто»); `install.ps1` на Windows не прогонялся — бэклог, п. 7.

### СЦ-04. Загрузить в claude.ai — веб и приложение Claude

**Кто.** Слушатель без Claude Code, с любым тарифом claude.ai, где доступны навыки
(по справке — включая Free) и включено выполнение кода.

**Шаги.** Скачать `zip/claude/preconstruction-ru.zip` → «Customize → Skills» → «+» →
«Create skill» → «Upload a skill» → в новом чате: «проработай идею: …».

**Ожидаемый результат.** Архив принят; навык виден в списке; в Claude Code той же учётной
записи (версия 2.1.273 и новее) он появляется сам.

**Что считается отказом.** «Skill folder name doesn't match the skill name»,
«Unexpected key(s) in SKILL.md frontmatter», «Invalid characters in skill name or description».

**Проверки.** `tools/check.py` — в архиве папка навыка в корне, её имя равно `name`,
в шапке только допустимые поля, в описании нет `<` и `>`, содержимое архива совпадает
с исходником. Сама загрузка не автоматизирована.

### СЦ-05. Загрузить в Perplexity — бесплатно

**Кто.** Слушатель без платного Claude.

**Шаги.** Скачать `zip/perplexity/preconstruction-ru.zip` → «Настройка → Навыки →
Создать навык → Загрузить навык».

**Ожидаемый результат.** Архив принят; навык ведёт исследование по очереди потоков.

**Что считается отказом.** «description exceeds maximum length of 1024 characters»;
«ZIP contains too many files».

**Проверки.** `tools/check.py` — описание не длиннее 1024 байт, `SKILL.md` в корне архива,
файлов меньше 100. Сама загрузка не автоматизирована.

### СЦ-06. Работать в любом чате — GigaChat, DeepSeek, ChatGPT

**Шаги.** Распаковать любой из архивов, приложить файлы к новому чату, первым сообщением:
«Следуй инструкции из файла SKILL.md; остальные файлы — справочники к ней».

**Ожидаемый результат.** Модель находит справочники по именам файлов без папки `references/`.

**Проверки.** не автоматизирована.

### СЦ-07. Выпустить новую версию

**Кто.** Автор.

**Шаги.** Правит `skills/` → поднимает версию в `.claude-plugin/plugin.json` и в
`metadata.version` обоих `SKILL.md` → `python3 tools/build_zips.py` → `python3 tools/check.py`
→ коммит и `git push`.

**Ожидаемый результат.** Пользователи плагина получают версию при обновлении маркетплейса;
архивы в `zip/` соответствуют исходнику; запись в `CHANGELOG.md`.

**Что считается отказом.** Навык поправлен, а архивы старые; версия в манифесте не поднята —
пользователи плагина правку не получат.

**Проверки.** `tools/check.py` — архивы совпадают с исходником, три версии равны.
