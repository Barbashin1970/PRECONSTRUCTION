# Урок: пределы LLM на примере чертежей фасадов

Реальный кейс, иллюстрирующий [критерий необходимости ИИ](04-ai-necessity-criteria.md):
**LLM хороши для исследования, но не для прямой автоматизации сложной техработы.**

## Вызов

Строительная компания хотела по PDF-чертежам фасадов автоматически получать ведомость
объёмов и материалов, затем сметы. Ожидание: загрузил чертёж → готовая таблица размеров.

## Что произошло с ChatGPT

- «ChatGPT 5 версии не распознаёт все цифры и **выдумывает результаты**».
- Размеры сливаются, часть чисел теряется. Пример: `670` и `450` → `670450`.
- По таким данным **невозможно посчитать площадь фасада**.

## Почему LLM так ошибаются

- LLM обрабатывает **токены**, не воспринимая изображение как объект.
- Не различает визуальные границы размеров и разметки.
- Не способен на **пространственный анализ**.
- Итог: ошибки, потеря времени, ручные проверки, падение ROI.

## Где проходит граница

| LLM/ИИ-агент подходит | LLM/ИИ-агент НЕ подходит |
|---|---|
| Анализ, обзоры, оценка зрелости решений | Точное распознавание размеров на чертежах |
| Сравнительные таблицы, сценарии, «корзины решений» | Пространственный анализ геометрии |
| Исследование инструментов, анализ отзывов, best-in-class | Прямая автоматизация сложной техработы |
| Расчёт срока окупаемости подписок, market research | Задачи, требующие компьютерного зрения |

## Как использовать ИИ правильно

1. Промпт-инженер описывает бизнес-задачу для ИИ-агента.
2. Агент проводит **market research**, формирует сравнение решений (точность, цена,
   автоматизация), предлагает специализированные платформы и обосновывает применимость.
3. Получаем список и рейтинг решений; можем обосновать собственную разработку, если аналогов
   нет; считаем выгоду и **можем отказаться**, если невыгодно.
4. Специализированное ПО (KREO, Togal.AI, Bluebeam Revu — см.
   [06](06-ai-research-tools.md)) внедряем **после теста на реальных чертежах**.

> **Мораль.** ChatGPT полезен для анализа и исследований, но не для прямой автоматизации,
> где нужны специализированные технологии (компьютерное зрение) и команда ML-инженеров.
> Это и есть практический смысл этапа «Применимость ИИ».
