# Preconstruction — база знаний

Методология **«Продакт-менеджмент (пресейл) строительных проектов с ИИ-помощниками»**:
как использовать ИИ на **исследовательской стадии** проекта (preconstruction / presale) —
ДО начала реализации, где экономятся 70–80% стоимости ошибок.

> **Центральный принцип.** ИИ — мощный инструмент **исследований и упаковки идеи**, а не
> обязательный компонент каждого продукта. Отдельно держим различие: «создано **С ПОМОЩЬЮ**
> ИИ» (вайб-кодинг) ≠ «содержит ИИ **ВНУТРИ**» (ML в продакшене).
