# Роли, экономика и карьера

Контекст «зачем»: почему освоить [пресейл](02-presale-5-stages.md) выгоднее, чем
ML-инженерию.

## Экономика прекострукшн (зачем это вообще)

- **70–80%** успеха проекта определяется ДО начала строительства.
- Формальный прекострукшн: **−30%** перерасход бюджета, **−25%** сроки.
- Качественная фаза → **30–40%** потенциальной экономии.
- **69%** проектов превышают бюджет на 10%+; **98%** мегапроектов — с задержками/перерасходом.
- ROI планирования: проекты $10–50M → **63%**; 1,5% бюджета на планирование → 4% прибыли (1 : 2.7).

Главные предотвратимые причины провалов: задержки, change orders, недочёты проектирования,
финансовые и операционные риски. ИИ-исследования на пресейле бьют по всем пяти.

## Строитель с ИИ-навыками ≠ ML-инженер

| | ML-инженер (создатель ИИ) | Строитель с ИИ-навыками (пользователь) |
|---|---|---|
| Делает | Модели с нуля | Применяет готовые инструменты |
| Знания | Математика, статистика, код | Промпт-инжиниринг, возможности/границы ИИ |
| Домен | Не знает стройку | Глубоко знает стройку + ИИ |
| Спрос | Единицы | Тысячи (массовый) |
| Обучение | 3–5 лет | 6–12 месяцев |

> Метафора: ML-инженер делает молоток; строитель с ИИ-навыками строит им дом.

## Новые роли с ИИ-компетенциями

Construction Data Analyst · AI Integration Specialist · AI-Powered Safety Officer ·
BIM Data Analyst / Digital Twin Specialist · AI Construction Project Manager.

**Зарплатный премиум: +25–40%.** Спрос на ИИ-навыки растёт ~10%/год.

## Карьерный путь (от пресейла к лидерству)

1. Освоение ИИ-исследований для пресейла (старт).
2. Учебные проекты (6 мес): градрегламенты, ИИ-визуализация, голосовые отчёты.
3. Другие этапы (1-й год): проверка норм (CodeComply, Document Crunch), ИИ-BIM, голосовые ассистенты.
4. Специализация (2–3 года): Safety Officer / BIM Data Analyst / AI Integration / Data Analyst.
5. Лидерство (5+ лет): Construction Tech & AI Lead, Digital Transformation Manager, CIO.

## Масштабирование на этапы строительства

Освоив ИИ на пресейле, специалист применяет его на всех этапах: проектирование (проверка
СП/ГОСТ, clash detection), стройка (контроль СИЗ компьютерным зрением: −95% аварий, −70%
затрат на персонал), голосовая документация (−10+ ч/нед админ-нагрузки, ROI 3,5×),
контроль качества (дроны, фото-анализ), пост-строительство (автоотчёты, punch lists).

> **Формула:** Строительная экспертиза × ИИ-навыки = Конкурентное преимущество.
