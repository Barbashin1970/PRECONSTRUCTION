# ИИ-инструменты для пресейл-исследований

Инструменты делятся на **исследовательские** (LLM/ИИ-агенты для этапов 1–5) и
**специализированные** (для технических задач, где LLM не годятся — см.
[07](07-case-llm-limits.md)).

## Исследовательские LLM / ИИ-агенты (бесплатные)

| Инструмент | Сильные стороны | Доступ | Ограничения |
|---|---|---|---|
| **DeepSeek** | Техническая точность, reasoning (R1), код, математика | `deepseek.com`, email, бесплатно | Нет голоса/картинок, базовый UI |
| **GigaChat** | Русский язык, стройтерминология, контекст РФ-нормативов, картинки (Kandinsky), презентации до 12 слайдов | `giga.chat`, Сбер ID | — |
| **Perplexity** | Поиск с источниками, актуальные данные | `perplexity.ai` | Бесплатно 5 запросов / 4 ч; Pro $20/мес → GPT-4, Claude |

Рекомендуемое распределение: **DeepSeek** — техэкспертиза и критика применимости ИИ;
**Perplexity** — идентификация и бизнес-анализ (нужны источники); **GigaChat** — упаковка
(русские тексты, презентации).

## Perplexity Spaces — командная работа

- Создать **Space** под проект; загрузить PDF-инструкции (методологию ролей).
- Задать **Custom Instructions** для ролевых агентов (бизнес-аналитик, маркетолог,
  системный аналитик ИИ, упаковщик) — см. [03](03-ai-agent-roles.md).
- Отдельный **тред на каждый этап** пресейла; совместный доступ команды.

## Инструменты упаковки

Gamma.app, Canva, Google Slides + ChatGPT, ГигаЧат — генерация презентаций. См.
[05](05-pitch-packaging.md).

## Специализированные платформы (НЕ LLM)

Для технических задач (например, распознавание размеров на чертежах) LLM «в лоб» не
работают. Используются специализированные решения:

- **KREO**, **Togal.AI**, **Bluebeam Revu** — takeoff / расчёт объёмов и смет по чертежам.
- Компьютерное зрение, BIM-плагины — для пространственного анализа.

> **Правило выбора.** LLM/ИИ-агент — чтобы **найти и сравнить** такие платформы (market
> research, рейтинг по точности/цене/ROI), а не чтобы выполнять саму техническую работу.
> Внедрять специализированное ПО только после теста на реальных чертежах. Подробно —
> [07 — пределы LLM](07-case-llm-limits.md).
